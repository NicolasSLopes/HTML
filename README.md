# 📖 HTML Dictionary

## Sobre o Projeto

O HTML Dictionary é um projeto desenvolvido inteiramente em HTML com o objetivo de servir como um guia de consulta rápida para as principais tags da linguagem HTML. A aplicação apresenta explicações claras e objetivas sobre cada elemento, auxiliando estudantes e desenvolvedores iniciantes no aprendizado e na compreensão da estrutura de páginas web.

Este projeto foi criado como uma forma prática de consolidar conhecimentos em HTML, demonstrando a utilização da própria linguagem para construir uma página informativa e organizada.

## Funcionalidades

- Consulta de diversas tags HTML.
- Descrição da finalidade de cada elemento.
- Estrutura simples e intuitiva para navegação.
- Conteúdo voltado para aprendizado e revisão de conceitos.
- Desenvolvimento realizado exclusivamente com HTML.

## Tecnologias Utilizadas

- HTML5

## Objetivo

O principal objetivo deste projeto é fornecer uma referência rápida e acessível para quem está aprendendo HTML, facilitando o entendimento das tags mais utilizadas no desenvolvimento web e suas respectivas funções.

## Aprendizados

Durante o desenvolvimento deste projeto, foram aplicados conceitos fundamentais de HTML, incluindo:

- Estruturação semântica de páginas.
- Organização de conteúdo em seções.
- Utilização de elementos de texto e listas.
- Boas práticas de marcação HTML.

## 🚀 Como Executar

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/html-dictionary.git
```

2. Acesse a pasta do projeto:

```bash
cd html-dictionary
```

3. Abra o arquivo `index.html` em qualquer navegador de sua preferência.
